# NetelsanSmartHome

Android akıllı ev istemcisi ve Express/MongoDB sunucusu.

1. MongoDB’yi başlat ve gerekiyorsa `MONGODB_URI` ortam değişkenini ayarla.
2. `BackendSunucu` içinde `npm ci` ve `node server.js` çalıştır.
3. `Android Uygulama` klasörünü Android Studio’da aç. Emülatörde sunucu için `10.0.2.2`, fiziksel cihazda geliştirme makinesinin adresi kullanılır.

Gradle Wrapper bileşenleri arşivde eksikse Android Studio ile projenin gerektirdiği yerel Gradle sürümünü seç.
